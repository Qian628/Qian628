### SynPeDAS — Synthetic Pedestrian Dataset for Safe Autonomous Driving
<img width="2923" height="1504" alt="image" src="https://github.com/user-attachments/assets/75f70530-412b-42c7-a34c-0ad853fd50cd" />

A research project exploring synthetic pedestrian video data for
safe autonomous driving. The repository includes real-world JAAD
clips, generated videos and video-generation prompts.

**My role:** Principle Investigator.
**Funding:** Supported by EPSRC and AISI through the Systemic AI Safety Grants [https://www.aisi.gov.uk/grants]
**Status:** Completed.
**Repository:** [Explore SynPeDAS](https://github.com/levilovearch/SynPeDAS)
